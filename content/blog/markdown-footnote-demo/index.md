写文章时，有时需要给正文里的说法补充参考资料或额外说明，但又不想打断阅读节奏——这就是**脚注**的用途。

## 基本用法

在正文需要标注的地方写一个 `[^标签]`，然后在文章任意位置（通常在文末）给出对应的解释：

```text
这是正文里的一个观点[^1]。

[^1]: 这是脚注的解释内容。
```

渲染后，正文处会出现一个上标的引用编号，文章末尾自动生成脚注列表；点击编号跳到脚注，再点击脚注末尾的 **^** 符号就能跳回正文。

## 小提示

- 脚注定义放在文末即可，Hugo 会自动把它们收集到页面底部的脚注区块。
- 脚注里也可以写链接、加粗等 Markdown 语法。
- 脚注末尾那个返回链接的样式（本站显示为上标的 **^**），由 `config/_default/hugo.yaml` 里的 `markup.goldmark.extensions.footnote.backlinkHTML` 控制。

---

[^1]: 静态网站生成器（Static Site Generator）在构建时把内容预先编译成纯 HTML，访问时不需要数据库和后端服务，因此速度快、安全性高。

[^2]: Goldmark 是一套符合 CommonMark 规范的 Go 语言 Markdown 解析器，也是 Hugo 自 0.60 版本起的默认渲染引擎。

[^note]: 所以即使你把标签写成 `[^note]`，页面上显示的仍会是连续的数字 1、2、3……标签名只方便你自己在写作时对应。
